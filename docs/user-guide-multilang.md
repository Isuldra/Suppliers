# Quick guide / Kort veiledning

The workspace currently uses Norwegian button labels. The instructions below keep those labels so you can find the controls. Reminder emails support Norwegian, English, Swedish, Danish and Finnish independently of the app language.

For file layouts and detailed behaviour, see the [Norwegian user guide](user-guide.md) and [Excel import reference](features/excel-import.md).

## Norsk

1. Importer en `.xlsx`-fil med arket `BP`: overskrifter på rad 5, data fra rad 6.
2. Kontroller e-post, språk og purredag i leverandørregisteret.
3. Velg ukedag eller `Alle`. Kontroller restlinjene og utelat det som er avklart.
4. Kryss av leverandørene, åpne gjennomgangen og kontroller hver forhåndsvisning.
5. Send gjennom Outlook. Flere mottakere kan skilles med komma eller semikolon.

`Avvent denne uken` utsetter leverandøren; `Ta med igjen` opphever utsettelsen. `Purre nå` åpner leverandøren til kontroll, men sender ikke.

Ved uklar sendefeil: kontroller Sendte elementer før ny sending. Ved feil i lagring av sendt historikk: behold Pulse åpen og prøv bare lagringen igjen. Historikken lagres på denne PC-en. Ny import nullstiller lokale kontaktendringer.

## English

1. Import an `.xlsx` file with a `BP` sheet: headers on row 5, data from row 6.
2. Check email address, email language and reminder days in the supplier register.
3. Choose a weekday or `Alle` (all). Review outstanding lines and exclude resolved ones.
4. Tick the suppliers, open the review and check each email preview.
5. Send through Outlook. Separate multiple email addresses with commas or semicolons.

`Avvent denne uken` defers the supplier for this week; `Ta med igjen` includes it again. `Purre nå` opens the supplier for review; it does not send.

If a send error leaves the outcome unclear, check Outlook's Sent Items before retrying. If sending succeeded but saving history failed, keep Pulse open and retry saving only. History is local to this PC. A new import resets local contact edits.

## Svenska

1. Importera en `.xlsx`-fil med bladet `BP`: rubriker på rad 5, data från rad 6.
2. Kontrollera e-postadress, e-postspråk och påminnelsedagar i leverantörsregistret.
3. Välj veckodag eller `Alle` (alla). Kontrollera återstående rader och undanta det som är klart.
4. Markera leverantörerna, öppna granskningen och kontrollera varje förhandsvisning.
5. Skicka via Outlook. Flera e-postadresser kan skiljas åt med komma eller semikolon.

`Avvent denne uken` skjuter upp leverantören denna vecka; `Ta med igjen` tar med den igen. `Purre nå` öppnar leverantören för kontroll utan att skicka.

Om resultatet av ett utskick är oklart, kontrollera Skickat i Outlook innan du försöker igen. Om meddelandet skickades men historiken inte kunde sparas, håll Pulse öppet och försök bara spara igen. Historiken är lokal på denna dator. En ny import återställer lokala kontaktändringar.

## Dansk

1. Importér en `.xlsx`-fil med arket `BP`: overskrifter på række 5, data fra række 6.
2. Kontrollér e-mailadresse, e-mailsprog og rykkerdage i leverandørregistret.
3. Vælg ugedag eller `Alle`. Kontrollér restlinjerne og udelad det, der er afklaret.
4. Markér leverandørerne, åbn gennemgangen og kontrollér hver forhåndsvisning.
5. Send via Outlook. Flere e-mailadresser kan adskilles med komma eller semikolon.

`Avvent denne uken` udsætter leverandøren denne uge; `Ta med igjen` tager den med igen. `Purre nå` åbner leverandøren til kontrol uden at sende.

Hvis resultatet af en afsendelse er uklart, kontrollér Sendte elementer i Outlook før et nyt forsøg. Hvis mailen blev sendt, men historikken ikke kunne gemmes, hold Pulse åben og prøv kun at gemme igen. Historikken er lokal på denne PC. En ny import nulstiller lokale kontaktændringer.

## Suomi

1. Tuo `.xlsx`-tiedosto, jossa on `BP`-välilehti: otsikot rivillä 5 ja tiedot riviltä 6 alkaen.
2. Tarkista sähköpostiosoite, viestin kieli ja muistutuspäivät toimittajarekisteristä.
3. Valitse viikonpäivä tai `Alle` (kaikki). Tarkista avoimet rivit ja jätä selvitetyt rivit pois.
4. Valitse toimittajat, avaa tarkistusnäkymä ja tarkista jokainen esikatselu.
5. Lähetä Outlookin kautta. Erota useat sähköpostiosoitteet pilkulla tai puolipisteellä.

`Avvent denne uken` siirtää toimittajan muistutuksen tämän viikon osalta; `Ta med igjen` ottaa toimittajan mukaan uudelleen. `Purre nå` avaa toimittajan tarkistettavaksi eikä lähetä viestiä.

Jos lähetyksen tulos on epäselvä, tarkista Outlookin Lähetetyt-kansio ennen uutta yritystä. Jos viesti lähetettiin mutta historian tallennus epäonnistui, pidä Pulse auki ja yritä vain tallennusta uudelleen. Historia on paikallinen tällä tietokoneella. Uusi tuonti nollaa paikalliset yhteystietomuutokset.
