Versjon v1.5.5 Utgitt 02.10.2026 Windows 10 og 11 · 64-bit

Pulse finnes kun for Windows. Åpne denne siden på jobb-PC-en din for å laste ned.

NYTT I DENNE VERSJONEN

Purringer sendes igjen via Outlook. 1.5.4 lastet e-posten som .eml, som Outlook avviste med «Ugyldig bane eller URL-adresse».

SLIK INSTALLERER DU

  1. Lukk Pulse hvis du har en eldre versjon åpen.
  2. Kjør filen du lastet ned. Installeren kan be om administratorrettigheter.
  3. Start Pulse og importer innkjøpslisten som før.

OPPDATERINGER

Installert Pulse ser etter ny versjon ved oppstart og hver 6. time. En nedlastet versjon installeres når du lukker Pulse. Portable-versjonen må lastes ned og byttes ut manuelt.
